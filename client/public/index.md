# Mean Cuisines

**Cook Like a Machine, Eat Like a King.**

Mean Cuisines is a batch-cooking / meal-prep planner at [https://meancuisines.com](https://meancuisines.com). You pick the appliances in your kitchen, choose recipes that can run together, and the site builds a parallel cook schedule so more than one dish finishes in the same window.

## Use the planner (humans)

Open [https://meancuisines.com/](https://meancuisines.com/). Select oven, stove, air fryer, Instant Pot, microwave, and how many burners you have. Then pick recipes. The app only offers recipes your equipment can actually cook, and it lays out start and end times so you are not fighting for the same burner.

## Use the API (agents)

Start at [llms.txt](https://meancuisines.com/llms.txt) and the [agent guide](https://meancuisines.com/llms-full.txt).

- Catalog: [GET /api/recipes](https://meancuisines.com/api/recipes)
- Schema: [openapi.json](https://meancuisines.com/openapi.json)
